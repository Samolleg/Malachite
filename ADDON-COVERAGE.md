# Профиль скриптов JamaisVu · Малахит 0.3

Источник профиля — Release-аддон, source commit `6955e6c9470f9e33683567300c6339f620de22dc`. Регистрации извлечены из `NewScriptCommands.cpp`, правила необязательных/повторяемых аргументов и замены штатных команд — из `Patches/Scripts.cpp`, преобразование ветвлений — из `MobIfElse.h`. SHA исходника каталога встроен в `Data/addon.json`. Профиль не зависит от дальнейших изменений файлов игры и требует обновления при изменении языка аддона.

| Возможность аддона | Поддержка в редакторе |
|---|---|
| Все 93 Release-регистрации | Имена, порядок типов, возвращаемые значения, русское назначение и роли аргументов |
| Переопределение штатных функций | ConsoleString, Add, Mul, Random, ResetTarget используют контракт аддона; исходный реестр 214 команд сохранён отдельно |
| Необязательная группа `?` | Все разрешённые формы, в том числе CreateVoiceFX/Wait с 3 или 5 аргументами, GetUnitExp с 1 или 2 |
| Повторение последнего аргумента `+` | Минимальное число, тип каждого повторения, вложенные вызовы; подсказка показывает все переданные значения |
| Возвращаемые float/string/object/group | Проверка вложенных выражений, присваиваний и числовых условий |
| `if/then/else`, вложенный `if` | Перенесён текстовый преобразователь: короткое замыкание условий, один выбор ветки, прямые переходы в том же потоке, сохранение строк |
| Старый верхний `if` без else | Сохраняет правило ожидания, не превращается в условие однократного выбора |
| Вложенность и синтаксические ошибки | Предел 64 списка действий; несогласованный/повторный else, else if без скобок, отсутствующий then |
| Команды с телом | Штатные For/ForIf; Debug IfThen/While/ForInStr распознаются, но недоступны в Release; ожидание речи в синхронном теле запрещено |
| Служебные JmvBranchUnless/Skip | Распознавание и описание, проверка постоянного смещения; полный динамический адрес перехода требует исполнения |
| Исправления лексера | Целые имена с префиксами ключевых слов, `_` и `#`, русские строки CP1251, комментарии, пути без выдуманного экранирования |
| Debug-команды | Все 10 описаны; при использовании выдаётся конкретная ошибка отсутствия в Release, а не UNKNOWN |
| Карточка else | Добавление/удаление, включая пустую ветку; одна отменяемая операция; сложные структуры остаются редактируемыми в коде |

Текст преобразования используется для анализа и проверок соответствия, но не подменяет редактируемый сценарий: экспорт сохраняет авторские if/else, комментарии, кодировку, seed и посторонние MOB-чанки.

У известных команд не выдаётся предупреждение «возможно, команда аддона». У действительно отсутствующих в профиле и декларациях имён предупреждение остаётся. Наличие этой справки не означает присутствия всех команд в другом моде.

## Выявленные несоответствия исходного аддона

Редактор не меняет native-обработчики и не исправляет их сигнатуры выдуманными параметрами:

- `DistancePointPoint`: регистрация двух чисел, обработчик читает четыре.
- `CheckObjectFlag`, `CheckObjectFlag2`: регистрация числа и объекта, обработчик читает второй элемент массива объектов вместо числового параметра.
- `CastSomeSpellTarget`: регистрация одного числа, обработчик дополнительно читает второй числовой параметр.

При таких вызовах отображается предупреждение о несоответствии с объяснением. Это подтверждённое чтением исходника расхождение, а не утверждение о воспроизведённом игровом сбое.

## Границы

Это поддержка фронтенда скриптов аддона: чтение, структура, типы и объяснения. Редактор не исполняет мир, Lua, сетевые события или звук, не загружает игровую DLL в свой процесс и не является полным оригинальным компилятором движка. Доступность объектов, файлов в RES, эффекты настроек и динамические значения требуют отдельных проверок. Оригинальная грамматика движка проверяется частично; равенство текстового прохода аддона не доказывает принятие всего сценария оригинальным компилятором.

Неизменённое ограничение MOB-адаптера: `ZoneMainMenuNew.mob` с внутренним NUL отвергается явно; это не признание карты испорченной и не ограничение конкретной команды аддона. Из 153 установленных карт 152 доступны для текущего прохода.

`Import-AddonCatalog.ps1` обновляет регистрации из явно выбранного исходника; это не автоматическое обновление игры. `Verify-AddonLowering.cpp` и `Verify-AddonParity.ps1` сравнивают управляемый проход с оригинальным заголовком аддона; стенд и игровые тексты не входят в готовую папку приложения.
