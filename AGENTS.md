# Малахит: независимый модуль

Общая дорожная карта: `../work/investigations/project-roadmap.md`, родитель
`MOB-QUEST-EDITOR-001`. Корневые инструкции проекта сохраняют силу.

- Эта задача владеет исходниками QuestStudio, включая modules и tests. SDK,
  загрузчик, службы и основной UI Редактора БД принадлежат задаче «Редактор БД».
- Обычная команда обновления: `./Update-Module.ps1`. Она собирает только Малахит
  с бинарным SDK из `../EvilIslands.DatabaseEditor/handoff/current`, затем
  вызывает host-owned `tools/Update-Malachite.ps1 -PackagePath`.
- Постоянная установка — `EvilIslands.DatabaseEditor/handoff/current`.
  Не создавать датированные комплекты по умолчанию и не пересобирать App/Core.
  Не копировать модуль вручную в обход host updater. Редактор должен быть закрыт.
- По согласованному решению владельца совместимые будущие обновления модуля
  не требуют участия задачи БД. Изменения SDK и новые возможности хоста
  предварительно согласовывать. Не обновлять current параллельно с её владельцем.
- Для проверки сборки без установки использовать `./Update-Module.ps1 -BuildOnly`.
  Временный пакет сохраняется для диагностики. Сборка сама по себе не доказывает
  работу пользовательского интерфейса или игровых сценариев.
