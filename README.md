# Малахит · Мастерская квестов 0.3.1

Встраиваемый модуль Малахита развивается отдельно от самостоятельной версии. Для его сборки и обновления в постоянном Редакторе БД закройте редактор и выполните `./EvilIslands.QuestStudio/Update-Module.ps1` из корня workspace. SDK берётся из `EvilIslands.DatabaseEditor/handoff/current`, модуль устанавливается в `Modules/malachite/current`; основной редактор не пересобирается. `-BuildOnly` собирает модуль без установки. Подробности — в [modules/README.md](modules/README.md).

Исправление 0.3.1: схема, выделение списка и инспектор следуют за курсором и переходом к ошибке. Во время ввода правая панель не отключается целиком и не мигает белым; устаревшие поля карточки временно защищены от записи. Некорректный числовой аргумент — ошибка, неизвестное имя переменной — предупреждение с учётом возможного внешнего объявления. Статус после анализа обновляется.

Локальный Windows-редактор MOB-сценариев «Проклятых Земель». Графитовый интерфейс с малахитовыми акцентами; исходный код, схема вызовов и карточки этапов работают с одним документом.

## Запуск

Запустите `Malachite.QuestStudio.exe` из готовой папки. Нужен .NET Desktop Runtime 9; на машине сборки установлен 9.0.18. Установщик и изменение игры не требуются. Первый экран содержит учебную цепочку «Потерянное письмо», не привязанную к игровой карте.

## Работа

1. **Открыть…** принимает `.mob`, `.txt`, `.scr` и проект `.malachite`. Текст: UTF-8 (с BOM или без) либо Windows-1251. MOB сохраняет собственную Windows-1251.
2. В **Этапах** выберите Script: схема покажет прямых вызывающих и вызываемых соседей, код перейдёт к определению. Стрелка означает запуск экземпляра Script, а не ожидание завершения квеста. На каждой стороне отображаются до пяти соседей; все вызовы остаются в коде.
3. Простая структура с одним `if/then` и необязательным `else` редактируется карточкой. **Применить карточку к коду** создаёт одну отменяемую правку. Переключатель **Использовать else** добавляет или удаляет ветку, включая пустую; это влияет на момент проверки условия. Пока карточка не применена, код защищён от конкурирующей правки; переход спрашивает, применить или отбросить черновик. Сложные скрипты редактируются в коде.
4. **Добавить этап** создаёт DeclareScript и одноразовый Script с собственным GS-ключом. Выберите родительский этап или WorldScript, затем новый Script в инспекторе и **Добавить вызов**. Условия, флаги, порядок и реальное игровое событие задаются автором. UI добавляет только вызовы без параметров; остальные доступны в коде.
5. **Функции** содержит 302 команды профиля JamaisVu Release: 214 штатных и 93 регистрации аддона, из которых 5 заменяют штатные. Ещё 10 Debug-команд описаны отдельно как недоступные в Release. У каждой штатной команды есть русское описание, роли всех аргументов и возвращаемое значение. Поле поиска фильтрует имена и смысл. **F1** на имени открывает объяснение. Неустановленные детали и исторические неактивные обработчики явно помечены; неизвестные команды аддона не объявляются несуществующими.
6. **Папка MOB…** индексирует MOB непосредственно в выбранной папке, без рекурсии и без записи в них. **GS** показывает буквальные чтения/записи ключей в текущем черновике и снимке других карт. Переход к чужой карте сверяет её хэш; при изменении файла нужен новый индекс. Файлы из RES, порядок подключения map.txt и динамические имена не разрешаются.
7. **Проверить / F5** запускает локальные правила. Ошибка ведёт к строке. Компилятор движка не вызывается; успешная локальная проверка не гарантирует работоспособность квеста.
8. **Сохранить проект / Ctrl+S** записывает новый `.malachite`: код и точный исходный MOB-контейнер, если он был открыт. **Экспорт…** создаёт отдельный MOB или текст. Существующие файлы никогда не перезаписываются: выберите новое имя. При локальных ошибках MOB-экспорт блокируется; черновик проекта и текст сохранить можно.

Ctrl+O — открыть; Ctrl+F — поиск в обозревателе; Ctrl+Z / Ctrl+Y — отмена/повтор в текстовом поле. Сохранение проекта не устанавливает карту в игру.

## Наведение и шапка в версии 0.2

Белая системная полоса заменена собственной графитово-малахитовой шапкой. Слева название документа, справа свернуть/развернуть/закрыть. Шапка сохраняет перетаскивание и системное меню по правой кнопке; края окна остаются изменяемыми по размеру.

Наведите мышь на имя в **коде, полях карточки, списке этапов/функций, списке целей вызова или на схеме** и задержите примерно на полсекунды. Подсказка появится рядом. Для вызова в коде показываются фактически переданные значения. Подсказки поддерживают прокрутку длинного объяснения. Все команды аддона имеют описания; необязательные группы и повторяемые аргументы показаны в сигнатурах и проверяются по действующей регистрации.

Для каждого пользовательского Script объяснение собирается из текущего тела: параметры, условия, действия, вложенные ветви и явные вызывающие Script. Соседние if показываются отдельно. KillScript не прекращает оставшиеся действия своей уже начатой ветки, но в справочном планировщике останавливает дальнейшие верхнеуровневые проверки экземпляра. Длинное объяснение ограничено с явным указанием продолжения в коде. Для отсутствующего тела показывается декларация и отсутствие данных, а не выдуманный сюжет.

Каталог `Data/help.tsv` содержит описания штатного движка, `Data/addon-help.tsv` — объяснения всех обработчиков аддона. `Data/addon.json` извлечён из NewScriptCommands.cpp профиля Release (source commit 6955e6c9470f9e33683567300c6339f620de22dc); тот же исходник содержит десять Debug-only записей. Это объяснения для человека, не доказательство неизменности обработчиков конкретного аддона. Сигнатуры хранятся независимо в `Data/commands.json` и не менялись ради описаний.

## Проверки и ограничения

Проверяются границы/дубликаты MOB-чанков, скобки, строки, базовая структура объявлений и if/then, число аргументов, определимые типы по штатному реестру, глобальные аргументы перебора, часть подозрительных повторов. Неизвестный тип/команда сохраняют статус неопределённости. Это частичный анализатор, а не полная реализация компилятора. Показаны первые 500 замечаний; счётчики и экспорт учитывают весь результат.

Экспорт сохраняет seed, нулевой хвост скрипта, незатронутые чанки, кодировку и исходные байты при отсутствии изменений; длины контейнера пересчитываются. Повторный разбор результата обязателен. Нулевой байт внутри исходного текста, повреждённые/дублированные чанки, непредставимые в CP1251 символы и превышение лимитов отклоняются. Лимиты: вход 128 МиБ, интерактивный анализ 4 МиБ символов.

Не реализованы: QDB/RES-редактор и разрешение связанных текстов/наград, полная проверка достижимости и эмуляция планировщика, оригинальный компилятор, проверка ID объектов и динамических ресурсов, визуальное редактирование произвольной вложенной структуры, миграция сохранений и установка в игру. Папка в этой версии индексируется заново после открытия приложения. Изменение MOB не обновляет автоматически скрипт, уже сохранённый в старом игровом save.

## Разработка

Собственный отдельный проект `EvilIslands.QuestStudio`, C# / WPF / net10.0-windows, без внешних NuGet-зависимостей. Реестр встроен в сборку; источник — корневой `Реестр_штатных_MOB_команд_ChatGPT.json` от 16.09.2026. `MobDocument.cs` следует действующему chunk-aware формату и алгоритму проектного инструмента `work/inventory_mob_scripts.py`. Native addon и Database Editor не изменялись.

```powershell
dotnet build EvilIslands.QuestStudio.csproj -c Release
dotnet bin/Release/net10.0-windows/Malachite.QuestStudio.dll --verify <evidence-directory> <optional-installed-Maps-directory>
```

Проверка не показывает окно: проверяет контейнеры, анализатор, проекты, WPF-обработчики и рисует интерфейс в PNG. Отчёт `report.json` отличает принятые файлы от явно отклонённых. Проверка реальной карты — только чтение, преобразования выполняются в памяти. Проверка реальными файлами не означает компиляции или запуска игры.

Общая дорожная карта: `../work/investigations/project-roadmap.md`, MOB-QUEST-EDITOR-001. Эта версия — первый рабочий этап; дальнейшая семантика и игровая приёмка остаются открытыми.
