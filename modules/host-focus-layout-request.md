# Предложение хосту: больше места для Малахита

Статус: конкретный запрос на согласование. SDK и основной редактор этой задачей не изменены.

Малахит уже умеет сворачивать собственный список скриптов, инспектор и проверки. Чтобы освободить всю ширину окна от внешнего меню БД, нужна функция хоста. Прямой поиск родительских элементов WPF и изменение чужой вёрстки не используются.

Предлагается необязательное расширение SDK V1:

```csharp
public interface IModulePresentationHost
{
    bool FocusMode { get; }
    Result SetFocusMode(bool enabled);
    event EventHandler? PresentationChanged;
}
```

Capability: `module.presentation.v1`. Отсутствие capability сохраняет обычную работу модуля; новая DLL не требует расширения как обязательного условия загрузки.

Хост знает владельца запроса через объект контекста модуля. При включении режима он сохраняет текущую ширину и видимость внешнего меню и даёт активному модулю оставшуюся область. Общая верхняя строка окна с Undo/Redo, «Макет» и кнопками окна остаётся доступной. При выключении, смене раздела, выгрузке или ошибке модуля хост возвращает прежнюю вёрстку. Неактивный модуль не может менять представление другого раздела. Операция UI не изменяет dirty, документы, разрешения файлов или историю Undo.

В Малахите будет одна кнопка «Больше места» / «Вернуть меню БД». Она появится после согласования и реализации хостом этого интерфейса. Эта записка не поручает задаче БД выполнять новые изменения без решения владельца.

Критерии: включение/выключение при открытой карте; возврат к разделу БД с прежней шириной; доступность Undo/Redo и возврата меню с клавиатуры; независимая загрузка прежних модулей и нового Малахита; отсутствие изменений документов и истории при смене представления.
